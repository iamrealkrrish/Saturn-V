# Saturn-V
Your multi-stage launch vehicle for automated crypto spot trading.

Overview
Saturn-V is a lightweight, configurable automated spot trading bot built to execute your strategies seamlessly across multiple exchanges. Designed for simplicity and control, it handles continuous market monitoring, target profit-taking, strict stop-loss measures, and a custom rebuy loop so you can automate your trades without getting bogged down by complex infrastructure.

Whether you're executing small test hops or aiming for escape velocity, Saturn-V provides a reliable foundation for algorithmic spot trading.

Key Features
Multi-Exchange Support: Plug in your preferred exchange API credentials and route your trades dynamically.

Custom Profit & Loss Margins: Define your exact risk appetite with user-configured target profit thresholds and stop-loss triggers.

Smart Rebuy Logic: Features an integrated stop-loss rebuy mechanism to automatically catch dips and reposition when markets correct.

Lightweight & Modular: A clean, straightforward codebase designed for easy reading, tracking, and future feature expansion.

Getting Started
Prerequisites
Python 3.10+ (or your preferred environment)

Active API keys from your target supported exchange.
